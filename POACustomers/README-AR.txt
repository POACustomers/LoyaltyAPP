إصلاح صلاحيات الطلبات لحساب GM/Admin — Dina’s Corner

سبب المشكلة: صفحة Branch Orders كانت تمنع غير Staff المعيّن لفرع، وكذلك صلاحيات Supabase كانت تقصر قراءة الطلبات على الموظف المسؤول عن الفرع.

ارفع الملفات التالية إلى نفس المسارات داخل المستودع:
- staff/staff-orders.html
- assets/pickup-orders.js
- sw.js

ثم افتح مشروع Supabase الصحيح الخاص بـ Dina’s Corner → SQL Editor → New query، وشغّل ملف POAC-GM-ALL-BRANCH-ORDERS-FIX.sql مرة واحدة.

بعد الإصلاح:
- GM/Admin النشط يستطيع عرض وإدارة طلبات كل الفروع دون الحاجة إلى ربطه بفرع.
- Staff يظل محصورًا في الفرع المعيّن له.
- العميل يظل قادرًا على رؤية طلباته فقط.
- إلغاء أي طلب إداري يتطلب كتابة سبب.

تم فحص بناء JavaScript وقواعد الصلاحيات ومسارات الأرشيف محليًا، لكن الإصلاح لم يُختبر على قاعدة Supabase الحية.
