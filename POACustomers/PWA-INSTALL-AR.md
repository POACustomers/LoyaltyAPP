# POACustomers — نافذة التثبيت المختصرة

- عند فتح رابط QR أول مرة في جلسة المتصفح، تظهر نافذة صغيرة بدل صفحة تعليمات طويلة.
- Android/Chrome: إذا أتاح المتصفح حدث التثبيت الرسمي، يفتح زر «تثبيت التطبيق» نافذة التثبيت الرسمية بعد ضغط العميل.
- iPhone/iPad: يظهر زر «إضافة إلى الشاشة الرئيسية». لا يقدم iOS واجهة برمجية لفتح أمر الإضافة تلقائيًا؛ الضغط على الزر يعرض تلميحًا مختصرًا جدًا: مشاركة Safari ← إضافة إلى الشاشة الرئيسية.
- يمكن إغلاق النافذة أو اختيار «لاحقًا»، ويظل زر صغير لإعادة فتحها متاحًا على صفحة البداية.
- إذا كان التطبيق مثبتًا ويعمل بوضع standalone، لا تظهر النافذة.
- تم رفع رقم ذاكرة التخزين المؤقت في `sw.js` حتى يتلقى العميل النسخة الجديدة بدل الملف القديم المخزّن.

## تركيب التحديث
استبدل الملفات داخل جذر مستودع GitHub بهذه المسارات بالضبط:
- `POACustomers/index.html`
- `POACustomers/sw.js`
- `POACustomers/assets/pwa-install.js`
- `POACustomers/assets/pwa-install.css`

ثم Commit إلى `main` وانتظر نجاح GitHub Pages. لا تغيّر Supabase أو أي مفاتيح اتصال.
