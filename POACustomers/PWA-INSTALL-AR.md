# تحديث نافذة تثبيت POACustomers / Dina's Corner

## ما الذي تغيّر؟
- استبدال نافذة التعليمات الكبيرة ببطاقة صغيرة مثبتة أسفل الشاشة، من دون تعتيم أو تمويه بقية الصفحة.
- إزالة زر التثبيت العلوي المكرر؛ تظهر دعوة التثبيت تلقائيًا عند فتح الموقع من المتصفح، ويمكن إغلاقها باختيار «لاحقًا».
- Android: زر «تثبيت التطبيق» يفتح نافذة التثبيت الرسمية عند توفر `beforeinstallprompt`.
- iPhone/iPad: زر «إضافة للشاشة الرئيسية» يكشف جملة واحدة قصيرة فقط بعد الضغط، لأن Safari لا يوفر API لفتح إجراء الإضافة مباشرة من صفحة الويب.
- الحفاظ على تبديل اللغة وحفظ اختيار المستخدم، وتحديث نسخة Service Worker لإزالة الملفات القديمة من الذاكرة المؤقتة.

## الملفات المستبدلة
- `POACustomers/index.html`
- `POACustomers/sw.js`
- `POACustomers/assets/pwa-install.js`
- `POACustomers/assets/pwa-install.css`

## النشر
استبدل الملفات الأربعة في المسارات نفسها داخل مستودع `POACustomers/LoyaltyAPP`، ثم احفظها على فرع `main` وانتظر نجاح GitHub Pages. افتح الموقع في Safari أو Chrome واختبره من تبويب عادي. للتأكد من التحديث أغلق التبويب القديم وافتح الرابط مجددًا.

رابط البداية المستخدم مع QR:
`https://poacustomers.github.io/LoyaltyAPP/POACustomers/index.html`

ملاحظة: لا يستطيع موقع ويب تثبيت نفسه بصمت؛ Android يتطلب تأكيد مربع التثبيت، وiOS يتطلب تأكيد «إضافة إلى الشاشة الرئيسية» من Safari.
