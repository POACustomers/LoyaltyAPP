# تحديث منيو Dina's Corner المستقل — تعليمات التثبيت

## ما الذي تغير؟
- صفحة `menu.html` أصبحت منيو عرض عام مستقلًا: لا تسجيل دخول، ولا سلة، ولا إضافة طلبات.
- الضغط على الصنف يفتح شاشة تفاصيل مستقلة داخل نفس رابط المنيو، مع إمكانية الرجوع للقسم.
- رابط الصنف يمكن مشاركته مباشرة عبر معاملات `?category=...&item=...`، بينما يظل رابط NFC الأساسي ثابتًا.
- تصميم الموبايل يستخدم ألوان Dina's Corner الحالية من إعدادات العلامة التجارية، ولا يغير صفحات الطلبات.
- أضيفت حقول اختيارية لتفاصيل الصنف: المكونات، الأحجام، الإضافات، ومعلومات مسببات الحساسية. تظل هذه البيانات اختيارية؛ لا تعرض الصفحة قسمًا فارغًا.
- لوحة GM تتيح تحرير هذه الحقول عند إضافة أو تعديل الصنف.

## خطوات النشر
1. احتفظ بنسخة احتياطية من المشروع الحالي.
2. ارفع محتويات مجلد `POACustomers` إلى المسار نفسه في مستودع GitHub، مع استبدال الملفات المحدثة.
3. افتح مشروع Dina's Corner في Supabase ثم SQL Editor.
4. شغّل مرة واحدة الملف `GM/PUBLIC-MENU-DETAIL-FIELDS.sql`.
5. افتح لوحة GM > Menu، وعدّل صنفًا تجريبيًا وأضف التفاصيل، ثم احفظه.
6. افتح `menu.html` من نافذة خاصة بدون تسجيل دخول، واختبر الأقسام ثم فتح الصنف والرجوع.

## الملفات المعدلة
- `menu.html`
- `assets/menu-display.js`
- `assets/menu-display.css` (رقم إصدار الرابط داخل HTML تم تحديثه لكسر الكاش)
- `GM/gm-menu.html`
- ملف CSS جديد: `assets/public-menu-premium.css`
- ملف SQL جديد لإضافة أعمدة التفاصيل الاختيارية.

ملاحظة: تمت مراجعة تركيب JavaScript محليًا فقط. لم يتم الاتصال بقاعدة Supabase الحية أو تنفيذ SQL عليها من هنا. صلاحية القراءة العامة لبيانات الأقسام والأصناف النشطة يجب أن تكون مضبوطة في سياسات RLS الحالية؛ لا تشغّل سياسة تسمح بالكتابة العامة.
