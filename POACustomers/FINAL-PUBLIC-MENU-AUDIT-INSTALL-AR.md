# مراجعة نهائية لمنيو Dina’s Corner المستقل

## ما تم إصلاحه
- ضبط عرض الصفحة على كامل عرض الموبايل، مع حد أقصى مناسب للشاشات الكبيرة.
- ضبط ارتفاع بطاقات الأقسام حتى لا تنهار إلى شرائط قصيرة.
- ضبط أحجام صور الأصناف وبطاقاتها للشاشات الصغيرة والمتوسطة والكبيرة.
- تصغير زر اللوكيشن إلى أيقونة صغيرة وتحتها «رأيك يهمنا» حتى يظل شعار Dina’s Corner واضحًا.
- استخدام Supabase client عام منفصل لا يحفظ جلسة العميل ولا يحتاج تسجيل دخول.
- جلب بيانات المنيو والأصناف والفرع من الجداول الصحيحة.
- الحفاظ على `location_id` في الرابط عند فتح قسم أو صنف والرجوع، حتى لا يضيع ربط NFC بالفرع.
- إذا فشل تحميل المنيو، تظهر رسالة واضحة وزر إعادة المحاولة بدل بقاء التحميل معلّقًا.
- رفع إصدار Service Worker وإضافة ملفات CSS/JS الجديدة إلى قائمة التخزين المؤقت.

## خطوات النشر
1. خذ نسخة احتياطية من المستودع الحالي.
2. ارفع محتويات مجلد `LoyaltyAPP-main` إلى نفس جذر مستودع GitHub مع استبدال الملفات المناظرة، أو استخدم ملفات Patch المحددة.
3. بعد اكتمال GitHub Pages افتح روابط NFC الثلاثة من نافذة خاصة.
4. إذا ظهرت رسالة صلاحيات أو بقي المنيو بلا أقسام، راجع سياسات RLS الحالية. إذا كانت الجداول والأعمدة المذكورة موجودة ولا توجد سياسة قراءة عامة مناسبة، شغّل `PUBLIC-MENU-READ-ONLY-ACCESS.sql` مرة واحدة في مشروع Dina’s Corner الصحيح.
5. تأكد أن Storage bucket باسم `poac-menu-images` عام (Public) إذا كانت صور المنيو لا تظهر. لا تجعل أي bucket آخر عامًا.
6. من GM > Branch Locations، ضع رابط Google Maps أو رابط كتابة التقييم الخاص بكل فرع في `Google Maps / review link`، ثم احفظ الفرع.
7. اختبر كل رابط NFC: يجب أن يفتح المنيو الموحد، وزر «رأيك يهمنا» يجب أن يفتح رابط Google الخاص بمعرّف ذلك الفرع.

## اختبارات مطلوبة بعد النشر
- موبايل بعرض 320px و360px و390px و430px.
- تابلت بعرض 768px، وشاشة كمبيوتر بعرض 1366px.
- فتح قسم، فتح صنف، الرجوع، ثم تحديث الصفحة؛ يجب أن يظل `location_id` موجودًا.
- فتح كل من روابط NFC الثلاثة والتأكد من اختلاف وجهة Google Maps بينها.
- فتح الرابط بدون تسجيل دخول.
- تعديل سعر/صورة منتج من GM والتأكد من ظهور التعديل في المنيو بعد إعادة التحميل.
- اختبار رابط التقييم عندما يكون `maps_url` رابطًا مباشرًا، وعندما يكون فارغًا (يستخدم البحث في Google Maps بعنوان الفرع).

## حدود التحقق
تم إجراء مراجعة ملفات وكشف أخطاء بناء JavaScript وفحص بنية ZIP محليًا. لم يتم الاتصال بمشروع Supabase الحي، ولم يتم نشر الملفات إلى GitHub، لذلك يجب تنفيذ اختبار قاعدة البيانات وروابط الفروع بعد الرفع.
