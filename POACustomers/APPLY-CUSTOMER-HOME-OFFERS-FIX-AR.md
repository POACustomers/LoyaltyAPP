# إصلاح ظهور العروض في الصفحة الرئيسية للعميل

## ما الذي تم تغييره؟
- تحديث `POACustomers/customer/customer-home.html` لتغيير إصدار `app.js` حتى لا تستخدم الصفحة رابط JavaScript القديم.
- تحديث `POACustomers/assets/app.js`: يجلب العروض النشطة، ويتحقق من تاريخ الصلاحية، ويعرض العروض السارية على صفحة العميل. إذا رجع استعلام Supabase بخطأ أو لم توجد عروض مطابقة، تظهر رسالة واضحة بدل البطاقة العامة القديمة، مع زر لإعادة المحاولة عند وجود خطأ.
- إضافة ملف SQL آمن لإعادة إعداد سياسة قراءة العروض الحالية للعملاء النشطين، وسياسات GM/Admin. الملف لا ينشئ أو يحذف أو يغيّر سجلات العروض.

## تركيب ملفات GitHub
من جذر المستودع `POACustomers/LoyaltyAPP` استبدل الملفات بحسب المسار الموجود في الحزمة:
1. `POACustomers/customer/customer-home.html`
2. `POACustomers/assets/app.js`

احفظ التغييرات في `main` وانتظر نجاح GitHub Pages.

## إعداد Supabase
في مشروع Supabase المرتبط بـ Dina's Corner فقط، افتح SQL Editor ثم New query، وانسخ محتوى:
`POACustomers/POACustomers-customer-home-offers-setup.sql`
ثم اضغط Run مرة واحدة. لا تستخدم ملف `00-core-bootstrap.sql` لهذا الإصلاح.

## الاختبار
افتح صفحة العميل بعد النشر واضغط `Ctrl + F5`، أو على الهاتف أغلق صفحة الموقع وافتحها مرة أخرى. يجب أن يظهر العرض النشط في قسم Special Offers. إذا فشل تحميل البيانات، ستظهر رسالة تفصيلية على الصفحة بدل البطاقة العامة، أرسل نصها لإكمال التشخيص.

## ملاحظة
لم يتم نشر التغييرات تلقائيًا إلى GitHub أو تشغيل SQL في قاعدة بيانات حية من هذه الحزمة.
