إصلاح السلة وشريط التنقل في صفحة المنيو

ارفع الملفات الثلاثة التالية إلى نفس المسارات داخل GitHub مع استبدال النسخ الحالية:
1) customer/customer-menu.html
2) assets/menu-display.css
3) sw.js

التغييرات:
- رجوع أيقونة السلة فقط أعلى صفحة المنيو، بلا كلمة Basket وبلا مستطيل أو خلفية أو ظل. يظهر رقم صغير فقط عندما تكون السلة تحتوي على أصناف. الضغط على الأيقونة يفتح السلة الحالية ويعرض الأصناف المضافة.
- تثبيت شريط التنقل السفلي على خمسة عناصر صحيحة: Home وMy Order وLocation وRewards وProfile. زر My Order يفتح customer-orders.html ولا يفتح صفحة المنيو.
- رفع إصدار Service Worker إلى v56 لمسح النسخة المخزنة القديمة بعد نشر الملفات.
- لا تغييرات في عرض صور الكاتيجوري أو المنتجات أو الصفحة الرئيسية.

بعد الرفع، افتح الموقع من Safari مع الإنترنت ثم أعد فتحه. لو ظلّ الهاتف يعرض النسخة القديمة، أغلق تبويب الموقع/تطبيق الشاشة الرئيسية بالكامل وافتحه من جديد.
