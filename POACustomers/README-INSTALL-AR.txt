إصلاح متابعة حالة الطلب — Dina’s Corner

لماذا؟ زر My Order كان يفتح customer-orders.html، وهي شاشة السلة/إتمام الطلب؛ وبعد نجاح إرسال الطلب تُفرّغ السلة عمدًا. سجل الطلبات وحالته موجودان في customer-order-history.html.

ارفع الملفات التالية إلى نفس المسارات في مستودع GitHub واستبدل الملفات المطابقة فقط:
- customer/customer-home.html
- customer/customer-menu.html
- customer/customer-orders.html
- customer/customer-order-history.html
- sw.js

ما يتغير:
- My Order في الصفحة الرئيسية والمنيو يفتح سجل الطلبات وحالاتها بدل السلة الفارغة.
- بعد تأكيد الطلب يظهر زر Track my order.
- صفحة سجل الطلبات تعرض شريط التنقل السفلي وتحدّث الحالات تلقائيًا كل 15 ثانية أثناء ظهور الصفحة.
- لا يتم تغيير طريقة إرسال الطلب أو الجداول أو SQL أو تصميم الصفحة الرئيسية باستثناء وجهة My Order.

مهم: هذا يصلح وجهة التنقل وعرض الحالة. إذا كانت صفحة سجل الطلبات تعرض رسالة خطأ من Supabase أو لا تعرض طلبًا بعد هذا التعديل، فستكون هناك مشكلة صلاحيات/حفظ في قاعدة البيانات، ويجب تشخيص رسالة الخطأ بدل تغيير رابط التنقل مرة أخرى.
