# رابط عرض منيو Dina's Corner فقط

## ما الذي يتغير؟
- `menu.html` صفحة عامة للعرض فقط: الأقسام، صور المنتجات، الأسماء، الوصف والأسعار.
- لا توجد سلة أو إضافة منتجات أو إرسال أوردر أو تسجيل دخول أو روابط لباقي صفحات التطبيق.
- يقرأ الرابط الأقسام والمنتجات النشطة من قاعدة بيانات Dina's Corner.
- يستمر الـ GM في إضافة وتعديل الأقسام والمنتجات من `GM/gm-categories.html` و`GM/gm-menu.html` كما هو معتاد.
- أُضيف زر `VIEW PUBLIC MENU` داخل صفحة إدارة المنيو لفتح صفحة العرض في تبويب جديد.

## مسار الرابط بعد رفع الملفات
`https://poacustomers.github.io/LoyaltyAPP/POACustomers/menu.html`

## خطوات التثبيت
1. استبدل الملفات الموجودة في مجلد `POACustomers` بالنسخة الموجودة في الحزمة، أو استخدم الحزمة الكاملة المحدثة.
2. ارفع التعديلات إلى GitHub وانتظر اكتمال نشر GitHub Pages.
3. افتح رابط المنيو من نافذة خاصة/متصفح غير مسجل الدخول.
4. إذا ظهرت رسالة أن المنيو غير متاح بسبب صلاحيات قاعدة البيانات، افتح مشروع Dina's Corner الصحيح في Supabase ثم SQL Editor.
5. راجع ملف `PUBLIC-MENU-READ-ONLY.sql` وشغّله مرة واحدة إذا كان مناسبًا لسياسات قاعدة البيانات الحالية. يمنح دور `anon` قراءة الأقسام والمنتجات النشطة فقط، ولا يمنحه صلاحية التعديل أو الحذف أو الإضافة.
6. اختبر أن GM يستطيع تعديل منتج، ثم افتح رابط المنيو العام وتأكد من ظهور التعديل.

## ملاحظات أمان مهمة
- صفحة المنيو لا تحتاج تسجيل دخول ولا تستدعي صفحات الطلبات.
- لا تضع مفتاح `service_role` أو أي مفتاح سري في ملفات المتصفح.
- محتوى أسماء المنتجات والصور والأسعار سيكون عامًا بطبيعته لأنه معروض للزوار.
- ملف SQL يضيف سياسات قراءة عامة فقط. لا يحذف بيانات ولا يعدّل الأسعار أو المنتجات. قبل تشغيله، راجع سياسات RLS الحالية إن كان مشروع Supabase يحتوي على سياسات مخصصة أخرى.

## ما لم يتم التحقق منه هنا
لم أتمكن من الاتصال بقاعدة Supabase الحية من بيئة الفحص؛ لذلك يلزم اختبار القراءة العامة بعد النشر. كما لم يتم النشر إلى GitHub نيابةً عنك.
