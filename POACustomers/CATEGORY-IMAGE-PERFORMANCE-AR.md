# تحسين سرعة صور التصنيفات — Dina’s Corner

## ما الذي تغيّر؟
- صفحة المنيو تعرض التصنيفات فور اكتمال استعلام التصنيفات، ولا تنتظر تنزيل قائمة كل المنتجات قبل إظهار أول شاشة. تُحمّل المنتجات عند فتح تصنيف فقط.
- أول صورة تصنيف تبدأ التحميل بأولوية أعلى، وأول صف يُحمّل مباشرة، وباقي الصور تستخدم التحميل الكسول و`decoding=async`. لم يتغير تصميم البطاقات أو ترتيبها.
- صفحة GM تضغط صورة التصنيف قبل رفعها (WebP عند دعم المتصفح، وإلا JPEG عند توفره) مع حد أقصى للضلع 960 بكسل؛ وتُرفع الصور الجديدة بمعرّفات ملفات جديدة وكاش طويل.
- أضيف زر اختياري **OPTIMIZE EXISTING IMAGES** في صفحة GM > Categories لتصغير الصور القديمة. يعالج صورة واحدة في كل مرة، ولا يحدّث رابط قاعدة البيانات إلا بعد نجاح الرفع. الملفات الأصلية في Storage لا تُحذف.
- تم تغيير رقم نسخة Service Worker حتى لا تستمر الصفحة في استخدام سكربت قديم.

## الملفات المعدلة
- `POACustomers/assets/menu-display.js`
- `POACustomers/customer/customer-menu.html`
- `POACustomers/menu.html`
- `POACustomers/GM/gm-categories.html`
- `POACustomers/sw.js`

## طريقة النشر
1. افتح مستودع GitHub الذي ينشر مجلد `POACustomers`.
2. استبدل الملفات الخمسة أعلاه في المسارات نفسها، ثم نفّذ Commit على الفرع الذي ينشر GitHub Pages. لا ترفع ملف ZIP داخل المستودع.
3. انتظر انتهاء نشر GitHub Pages.
4. سجّل الدخول بصلاحية GM وافتح `GM/gm-categories.html`. اضغط **OPTIMIZE EXISTING IMAGES** مرة واحدة، وافق على رسالة التأكيد، واترك الصفحة مفتوحة حتى تظهر نتيجة العملية.
5. افتح صفحة المنيو في Safari بتبويب جديد. إذا بقيت نسخة قديمة، أغلق التبويب وأعد فتحه؛ تم تحديث Cache version للمساعدة في تجاوز الكاش القديم.

## ملاحظات مهمة
- أداة الصور القديمة تحتاج إلى أن تكون الصور قابلة للقراءة من المتصفح عبر CORS وأن تسمح سياسات Supabase بالرفع وتحديث صفوف التصنيفات. الصور التي لا يمكن قراءتها/تصغيرها يتم تخطيها ولا يتوقف باقي العمل.
- صور Storage الأصلية لا تُحذف تلقائيًا، حتى لا نفقد مصدرًا أصليًا بالخطأ. قد تبقى الملفات الأصلية القديمة غير مستخدمة في Storage.
- لم يتم الاتصال بقاعدة Supabase الحية أو النشر إلى GitHub Pages أثناء إعداد هذه الحزمة. يجب نشر التعديلات وتجربتها بحساب GM ثم التأكد على Safari.
- هذا التعديل لا يعالج خطأ Android `AAPT2 process unexpectedly exit`؛ ذلك خطأ بناء منفصل يحتاج سجلّ الخطأ التفصيلي إذا استمر.
