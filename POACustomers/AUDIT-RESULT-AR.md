# نتيجة فحص النسخة — 22 أكتوبر 2026

## أهم النتائج
- كانت هناك ثلاث صفحات دخول/بوابات متنافسة: `index.html` في جذر المستودع، و`POACustomers/index.html`، وصفحة قديمة داخل `POAC-Multi-Client-Kit`. نسخة الـKit كانت تشير إلى ملفات لا توجد في ذلك المسار.
- كان الـService Worker في جذر المستودع والـService Worker داخل `POACustomers` يحذفان كل منهما كاش الآخر، كما كان الـService Worker المتداخل يحاول تحميل `manifest-customer.webmanifest` غير الموجود.
- صفحات العميل تشير إلى manifest غير موجود.
- رابط لوحة GM من صفحة إعدادات الإدارة يستخدم `gm` بحروف صغيرة، بينما المجلد الفعلي `GM` بحروف كبيرة؛ GitHub Pages حساس لحالة الأحرف.
- اختيار الـService Worker في `app.js` كان لا يتعرف على `/GM/` لأنه يفحص `/gm/` بحروف صغيرة دون تطبيع المسار.

## التعديلات في هذه النسخة
1. جعل الصفحة الرئيسية في جذر المستودع هي المدخل الموحد الوحيد؛ نسخة `POACustomers/index.html` أصبحت تحوّل إليها.
2. جعل صفحة `POAC-Multi-Client-Kit` توضّح أنها مساحة قوالب وليست بوابة تشغيل ثانية.
3. عزل أسماء الكاش بين الـService Worker الرئيسي والمتداخل حتى لا يحذف أحدهما ملفات الآخر، وإزالة مرجع الـmanifest غير الموجود.
4. إصلاح اختيار الـService Worker عند فتح صفحات GM وحالة الأحرف في رابط لوحة GM.
5. تصحيح روابط manifest في صفحات العميل إلى الملف الموجود.
6. ضبط manifest ليفتح صفحة الدخول الرئيسية ويستخدم نطاق التطبيق الرئيسي.

## التحقق المحلي
تم فحص روابط HTML المحلية وقوائم الملفات المخزنة مسبقًا في كلا الـService Workers، وفحص صياغة ملفات JavaScript محليًا.

## لا يزال يحتاج إعدادًا خارجيًا
لا يحتوي هذا الأرشيف على مجلد `supabase/` ولا على ملفات SQL أو Edge Function باسم `username-login` التي تشير إليها وثائق المشروع. لذلك لا يمكن إثبات أن تسجيل الدخول باستخدام اسم المستخدم لحسابات الإدارة وGM والموظفين مكتمل. صفحة الدخول تقبل البريد الإلكتروني مباشرة؛ أما أسماء المستخدمين لهذه الأدوار فتحتاج وظيفة Supabase آمنة منشورة وإعداد usernames والصلاحيات في قاعدة البيانات. لم يتم النشر إلى GitHub أو Supabase ولم يتم اختبار حسابات حية.

بعد رفع الملفات إلى GitHub، أغلق جميع تبويبات الموقع وأي نافذة PWA قديمة، ثم افتح الموقع من جديد واضغط `Ctrl + F5` حتى يتخلص المتصفح من النسخ القديمة.
