# إصلاح إدارة العروض — Dina's Corner

## ما الذي يتغير؟
- عرض العروض الحالية في قائمة الإدارة مع الاسم والتواريخ والحالة والصورة.
- زر EDIT يملأ النموذج ببيانات العرض المحدد.
- زر UPDATE OFFER يحفظ التغييرات، ويحتفظ بالصورة القديمة إذا لم تختر صورة بديلة.
- زر DELETE يطلب تأكيدًا قبل الحذف.
- زر REFRESH يعيد تحميل القائمة.
- عند فشل الاتصال أو الصلاحيات تظهر رسالة خطأ بدل استمرار `Loading offers…`.
- تحديث Service Worker وإزالة مرجع manifest غير موجود حتى يمكن تثبيت الكاش الجديد.

## الملفات المطلوب رفعها إلى GitHub
استبدل الملفات بنفس المسارات:
1. `POACustomers/GM/gm-offers.html`
2. `POACustomers/sw.js`

ثم شغّل SQL التالي مرة واحدة في SQL Editor لمشروع Supabase المتصل بهذا التطبيق:
`POACustomers/offers-edit-delete-policies.sql`

## التنصيب والتحقق
1. احفظ نسخة احتياطية من المستودع أولًا.
2. ارفع الملفين مع الحفاظ على المسارات واضغط Commit changes.
3. انتظر نجاح GitHub Pages.
4. في Supabase SQL Editor نفّذ ملف السياسات المذكور أعلاه فقط، وليس ملف core bootstrap.
5. افتح صفحة GM → Offers، واضغط Ctrl+F5. جرّب REFRESH ثم EDIT على عرض الاختبار.
6. لا تختبر DELETE على عرض مهم؛ استخدم عرضًا تجريبيًا حتى تتأكد من صلاحيات الحذف.

هذا التحديث يتيح الإدارة من الواجهة، لكنه لا ينشر الملفات على GitHub ولا ينفّذ SQL في مشروع Supabase نيابةً عنك. يجب تشغيل ملف السياسات حتى تعمل عمليات التعديل والحذف إذا كانت RLS تمنعها حاليًا.
