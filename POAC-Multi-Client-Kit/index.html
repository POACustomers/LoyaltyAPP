POAC • MULTI-CLIENT KIT

إضافة شركة جديدة إلى المنصة

هذا المجلد يحتوي على قالب وأداة تجهيز نسخة مستقلة لكل شركة. ليس هو تطبيق العميل أو بوابة الإدارة التي يستخدمها الزبائن.

1. قالب الشركةCLIENT_TEMPLATE/
انسخ القالب إلى tenants/اسم-الشركة/ ثم حدّث إعدادات العلامة التجارية.
2. قاعدة بيانات مستقلةأنشئ مشروع Supabase جديدًا لكل شركة؛ لا تشارك إعدادات أو بيانات Dina’s Corner.
3. ملف الإعدادأنشئ tenant.json من tenant.json.example وأدخل رابط ومفتاح Supabase العام للشركة.
4. بناء النسخةشغّل python POAC-Multi-Client-Kit/tools/build_tenant.py POAC-Multi-Client-Kit/tenants/اسم-الشركة/tenant.json --output dist/اسم-الشركة
تنبيه: لا تضع مفتاح service_role أو أي سر في ملفات HTML أو JavaScript. افحص RLS والصلاحيات واختبر كل الأدوار قبل بيع نسخة الشركة.
