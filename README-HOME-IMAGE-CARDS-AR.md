# تحديث الصفحة الرئيسية — صور كروت الوصول السريع

## ما الذي تغير؟
- إزالة قسم `Browse Categories` من الصفحة الرئيسية فقط. الكاتيجوري الفعلية تظل داخل صفحة المنيو.
- إبقاء بانر العروض في أعلى الصفحة.
- تحويل كروت الوصول السريع الخمسة إلى كروت بصور خاصة: Menu، My Profile، Locations، My QR Code، Offers.
- الاحتفاظ بروابط الكروت الحالية دون تغيير: المنيو، البروفايل، الفروع، QR الولاء، والعروض.
- تحديث كاش الـ PWA وإضافة الصور إلى قائمة الملفات التي يمكن حفظها للعمل دون اتصال.
- لا توجد تغييرات على Supabase أو SQL أو بيانات العملاء.

## الملفات المرفقة
- `POACustomers/customer/customer-home.html`
- `POACustomers/assets/style.css`
- `POACustomers/sw.js`
- الصور الخمس داخل `POACustomers/assets/home-cards/`

## طريقة التطبيق
1. فك ملف ZIP من جذر مستودع GitHub بحيث تندمج مجلدات `POACustomers/...` مع المجلدات الحالية.
2. استبدل الملفات الموجودة بالملفات المرفقة في نفس المسارات، وانسخ مجلد `assets/home-cards` بما يحتويه من الصور.
3. ارفع الملفات في Commit واحد.
4. افتح الموقع بعد النشر واضغط `Ctrl + F5`، أو أغلق التطبيق وأعد فتحه على الهاتف لتحديث الكاش.

## ملاحظات
- الصور المرفقة صور تصميمية مولدة لتوحيد مظهر الكروت، وليست صورًا فوتوغرافية لمنتجات الفرع.
- صورة كود الولاء زخرفية فقط؛ كود QR الفعلي يظل ديناميكيًا في صفحة `customer-card.html`.
- تم فحص بنية HTML وصياغة `sw.js` والتأكد من وجود الصور الخمس محليًا. لم يتم النشر على GitHub أو اختبار الموقع الحي من هنا.
