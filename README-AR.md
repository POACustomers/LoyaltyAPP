# تجهيز Android لمشروع Dina's Corner

هذه حزمة تجهيز أولية مبنية على ملف ZIP الذي أرسله المستخدم. تحتفظ بنسخة الويب الحالية داخل `public/` وتضيف إعداد Capacitor. **ليست APK جاهزة للتثبيت**؛ إنشاء مجلد Android والبناء النهائي يتطلبان تثبيت Node.js وAndroid Studio وأدوات Android SDK.

## قبل البناء
1. احتفظ بالنسخة الأصلية كما هي ولا ترفع هذه الحزمة فوق الموقع المنشور مباشرة.
2. افتح Terminal / PowerShell داخل هذا المجلد.
3. نفّذ:

```bash
npm install
npx cap add android
npx cap sync android
npx cap open android
```

4. داخل Android Studio انتظر اكتمال Gradle Sync، ثم جرّب التشغيل على هاتف Android أو محاكي.
5. لا تنشئ إصدارًا للبيع قبل اختبار تسجيل دخول العميل والموظف والإدارة، الروابط الداخلية، الصور والمنيو، الطلبات، الموقع، والاتصال بـ Supabase.

## ملاحظات مهمة
- نقطة الدخول المعبأة هي `public/index.html`، صفحة تسجيل الدخول العربية الموجودة في جذر النسخة الأصلية.
- ملفات الويب محفوظة تحت `public/` مع مساراتها النسبية الأصلية.
- لم يتم تغيير إعدادات Supabase أو قواعد البيانات.
- لم يتم التحقق من اتصال حي بقاعدة البيانات أو تنفيذ طلب حقيقي أثناء إنشاء الحزمة.
- معرّف التطبيق الحالي `com.dinascorner.app`؛ يجب تثبيته قبل النشر العام لأن تغييره لاحقًا قد ينتج تطبيقًا مختلفًا بالنسبة للمتجر.
- لإصدار iPhone نحتاج إعداد iOS منفصلًا وبيئة macOS مع Xcode.
