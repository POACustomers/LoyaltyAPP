تعديل عرض سبب إلغاء الطلب للعميل

الملفات المطلوب استبدالها في GitHub بنفس المسارات:
1) POACustomers/assets/pickup-orders.js
2) POACustomers/customer/customer-order-history.html

ما الذي تغير؟
- أصبحت صفحة سجل العميل تطلب حقلي cancellation_reason و cancelled_at من pickup_orders.
- إذا كانت حالة الطلب cancelled وكان السبب محفوظًا، يظهر للعميل داخل بطاقة الطلب تحت عنوان Cancellation reason.
- تم تغيير رقم إصدار ملف JavaScript في صفحة السجل حتى يحمّل المتصفح النسخة الجديدة بدل الملف المخزن مؤقتًا.

الاختبار:
- تم فحص صياغة JavaScript باستخدام node --check ونجح.
- لم يتم اختبار قراءة Supabase الفعلية؛ يلزم التأكد بعد رفع الملفات من ظهور السبب لطلب ملغي تجريبي.
- لا يشغّل هذا التعديل أي SQL ولا يغير قاعدة البيانات.
